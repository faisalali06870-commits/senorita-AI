# ⚡ SENORITA-AI (v2.5)
> **Your Emotionally-Perceptive Personal Desktop Companion, Live Vision Mentor & Coding Architect**

Senorita-AI is an advanced, Jarvis-grade AI desktop companion designed exclusively for Faisal. It combines sweet melodious neural female voices, emotional empathy, hands-free auto-listening, live screen sharing vision, in-chat live code execution, long-term memory, and full Windows PC control.

---

## 🌟 Key Features

1. **🎙️ Hands-Free Senorita Mode & Speech Engine**:
   - **Continuous Auto-Listening**: Talks naturally hands-free with auto-speech capture and generous human pause thresholds.
   - **Live Input Box Typing**: Words stream directly into the chat input bar in real time.
   - **Bilingual Acoustic Models**: Full support for `🇮🇳 Hindi / Hinglish` (`hi-IN`) and `🌐 English` (`en-IN`).

2. **🌸 Melodious Neural Female Voices (Studio EdgeTTS)**:
   - Ultra-sweet, expressive neural voices (Swara - melodious Hindi/Hinglish, Neerja - Indian English, Ana, Jenny, Sonia).
   - Voice customization settings (pitch, speed rate, voice testing).
   - Smart code filtering: Explains solutions conversationally while displaying code on screen.

3. **🖥️ Live Screen Sharing & Vision**:
   - Native one-click screen sharing (`[ 🖥️ Live Screen ]`).
   - Floating Picture-in-Picture live preview card with instant snapshot and manual analyze controls.
   - Gemini Multimodal Vision inspects live code, terminal errors, UI design, and browser pages on Faisal's monitor in real time.

4. **⚡ In-Chat Live Code Runner**:
   - Executes JavaScript (Node.js) and Python code directly inside the chat interface.
   - Collapsible live terminal console with stdout, stderr, execution duration, and exit codes.

5. **💖 Emotional Intelligence & Holographic Orb**:
   - Empathy engine detects user mood (stressed, happy, focused, tired, playful) and adapts personality warmth.
   - 3D Holographic Core Orb with dynamic pulsing emotion states and reactive audio rings.

6. **💻 PC Desktop & Hardware Automation**:
   - **App Launcher**: Opens VS Code, Chrome, Edge, Notepad, Calculator, Terminal, File Explorer, WhatsApp, Spotify, Paint, Task Manager.
   - **Hardware Control**: Volume up/down/mute, battery health check, sleep mode.
   - **Media Control**: Plays relaxing lofi, songs, or searches on YouTube and Spotify.
   - **System Navigation**: Opens Downloads, Desktop, Documents, or creates project folders.

7. **🧠 Long-Term Memory**:
   - Automatically remembers personal preferences, coding projects, and facts about Faisal permanently across sessions in `backend/memory.json`.

---

## 🚀 Quick Start (Single Launcher)

Simply double-click **`run_senorita.bat`** in the project folder!
It automatically frees port 3000, starts the Node.js backend, and launches **`http://localhost:3000`** in your browser.

*(Alternatively, run `cd backend && node server.js`)*
